# Infrastructure as Code CI/CD Pipeline

## Project Objective
Provision AWS infrastructure using Terraform and automate
application deployment using GitHub Actions.

## Technology Stack
- Terraform
- AWS VPC
- Amazon ECS Fargate
- Amazon ECR
- Application Load Balancer
- AWS IAM
- Amazon CloudWatch
- Docker
- GitHub Actions

## Planned Environments
- Development
- Staging
- Production

## Key Goals
- Infrastructure as Code
- Automated CI/CD
- Secure AWS access
- Deployment health checks
- Automatic rollback
- Infrastructure documentation
